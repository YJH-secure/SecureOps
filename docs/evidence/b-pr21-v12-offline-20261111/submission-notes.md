## 제출 파일과 비식별화

신규 테스트 및 증거 텍스트만 제출한다. B 운영 소스·정책 사본, 실제 서버 구성,
개인 사용자 경로, 실제 접속 IP·host, 비밀번호·개인키·토큰은 포함하지 않는다.
테스트의 root는 공개 SSH-01 정책 검사 대상이며 실제 로그인 인증정보가 아니다.
문서용 주소 대역과 `.invalid` 호스트는 합성 입력이며 실제 B 출력에는 남지 않는다.
C → D Draft PR #20의 브랜치/Commit과 기존 작업 파일은 보존했다.

Git은 텍스트의 CRLF/LF를 정규화할 수 있다. 과거 SHA-256 명세는 당시 로컬 원본 바이트 기준이며
체크아웃 환경에 따라 바이트 해시가 달라질 수 있다. 과거 명세를 덮어쓰지 않았다.
과거 보고서의 미제출 문구는 당시 상태를 뜻하며 이번 Draft PR 제출 상태와 구분한다.

초기 실패 원시 로그 `logs/01-b-pr21-to-d.log`와 `logs/04-d-full-with-fixed-sources.log`의
각 7행에는 unittest가 subtest 오류를 출력하면서 남긴 후행 공백이 있다.
원시 증거와 기존 해시를 보존하므로 이 두 행은 수정하지 않는다.
전체 strict 공백 검사는 해당 두 행을 보고하며, 이를 제외한 신규 테스트·문서·JSON·최종 로그는
별도 strict 검사 대상으로 확인한다. 최종 통과 로그의 공백 오류를 숨기는 예외는 적용하지 않는다.
